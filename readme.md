# Personal Profile Website

This is a simple, responsive personal profile website built using HTML5 and CSS3. It is designed to showcase an individual's bio, skills, and professional overview.

## Project Structure

- `index.html` - The main HTML document containing the structure and content.
- `style.css` - The stylesheet for modern, clean, and responsive visuals.
- `README.md` - Documentation and setup guide for the project.

## How to Run This Project

1. Clone or download this repository to your local machine.
2. Open the project folder.
3. Double-click the `index.html` file to view the website in any web browser.
